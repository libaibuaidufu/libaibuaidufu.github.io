windows的nginx举例，想做一个自启动服务

把下载好的WinSW-x64.exe复制到nginx目录，并去改名nginx-service.exe(可随意改名)。

然后新建一个nginx-service.xml

目录位置D:\Program Files (x86)\nginx-1.26.2\自行修改为自己位置。

这里执行同时也可以带命令的。在executable添加就行了

然后在D:\Program Files (x86)\nginx-1.26.2\目录下执行命令nginx-service.exe install
